# Estimator — Controls Reference

## Phase 1: Estimations Canvas

---

### Sidebar — Feature Setup

| Action | How |
|--------|-----|
| Add features | Type feature names in the text area (one per line), then click **Generate feature boxes** |
| Select a feature | Click the feature name in the sidebar tree |
| Select a task | Click a task row in the sidebar tree |

---

### Canvas — Navigation

| Action | How |
|--------|-----|
| Pan | Click and drag on any empty area of the canvas |
| Zoom in | Scroll wheel up |
| Zoom out | Scroll wheel down |
| Deselect | Click on any empty area of the canvas |

---

### Canvas — Feature Boxes

| Action | How |
|--------|-----|
| Move a feature box | Click and drag the feature box |
| Resize a feature box | Click a feature box to select it, then drag the left or right handles. Height adjusts automatically based on content. |
| Add a discipline card | Click the **+ Add discipline** button at the bottom of a feature box, then choose a discipline from the popup |

---

### Canvas — Discipline Cards & Tasks

| Action | How |
|--------|-----|
| Add a task | Click **+ Add task** at the bottom of a discipline card. Type the task name and press **Enter** |
| Edit a task label | Double-click the task label on the canvas |
| Cancel a label edit | Press **Escape** while the text editor is open |
| Select a task | Click anywhere on a task row |

---

### Sidebar — Task Inspector

Appears at the bottom of the sidebar when a task is selected.

| Action | How |
|--------|-----|
| Change estimate | Edit the number field or choose a unit (half-day / day / week / month) |
| View working days | Shown automatically below the estimate fields |
| Delete a task | Click **Delete task** in the inspector |
| Remove a discipline card | Click the **×** next to the discipline name in the sidebar tree (removes the card and all its tasks) |

---

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| `Ctrl + Z` | Undo |
| `Ctrl + Y` or `Ctrl + Shift + Z` | Redo |
| `Enter` | Confirm text edit |
| `Escape` | Cancel text edit |

---

### Data Persistence

Work is saved automatically to browser local storage. It survives closing and reopening the browser tab on the same machine. Multi-device sync requires the backend server (Phase 2+).
